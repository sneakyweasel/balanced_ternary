# Juggler residual-state sufficiency

Status: **EXPLORATORY**

Standalone application phase on the Juggler floor-power map. It is
**not** a Research Engine control-layer experiment and not a claim that
every positive integer reaches 1.

## Problem

After the layered rewrite, `ResidualStep` is a relation generated by a
realized excursion. Which coordinates of a candidate residual tuple
are sufficient to determine the next residual *constraint class*, and
which are already functions of the current integer or of the pair
\((\text{start},\text{current})\)?

## Exact statement

Keep the existing successor. Do not replace it with a state machine.

\[
\mathrm{ResidualStep}(x,y)
\iff
\exists\,a,b\ (b\ge 1\ \wedge\ x\ \text{follows}\ O^aE^b\ \wedge\ T_{O^aE^b}(x)=y).
\]

At a residual landing \(y\) on a chain from start \(n\) (the start
itself is index \(0\)), the candidate coordinates are locked as
follows.

| Coordinate | Meaning |
|---|---|
| \(y\) | current integer |
| parity | \(y\bmod 2\) |
| \(A\) | incoming odd-run length of the step that landed here; \(0\) at the start |
| \(G\) | combinatorial drift \(2^{a+b}-3^{a}\) of the incoming `oddEvenBlock`; \(0\) at the start |
| \(\rho\) | local floor remainder at \(y\) |
| cell | incoming first-even cell versus the previous state; at the start, first-even cell of \(n\) versus \(n\) |

\(A\) is incoming history, not the next odd run.

Two prediction targets stay separate.

- Intrinsic \(V(y)\): next excursion from the landing —
  \((a',b')\), cell of the next even residual versus \(y\),
  `residual_class(y,y')`, whether \(y'\) is odd-odd.
- Relative \(V_n(y)\): the same next step against the original start
  — `post_even_kind(n,y')`, `residual_class(n,y')`, and the scale
  facts \(n\le y'\) and (if \(y'\) is even) \(n^2\le y'\).

The Phase-0 question is whether any proper quotient \(Q\) that does
**not** contain the current integer itself determines \(V(y)\) or
\(V_n(y)\), and whether that \(Q\) has a nonempty fiber.

This says nothing about totality. Do not add `ResidualState`. Do not
extend `ResidualStep`. Do not prove a halt theorem.

## Counterexamples

- “incoming \((A,G,\mathrm{cell})\) is part of the next-constraint
  state”: same \(y=3\) from start \(3\) with \((A,G,\mathrm{cell})=(0,0,\mathrm{overshoot})\)
  and from \(69\to 117\to 3\) with \((2,23,\mathrm{overshoot})\);
  \(V(3)\) is identical. Also \(y\in\{1,5,9,11,21\}\).
- “\(V_n\) is a function of \(y\)”: start \(9\) has
  \(V_9(9)=\mathrm{STAY}\); landing \(9\) from \(53\) has
  \(V_{53}(9)=\mathrm{DESCENT}\).
- “\((G,\rho)\) is a proper quotient”: it separates non-start
  landings on this window, but every class is a singleton \(y\).

These kill the larger tuple as a new state. They do not produce a
halt statement.

## Results

Classification **RESIDUAL_STATE_NEEDS_X**, with secondary
**ESCAPE_STATE_REPLAY** and **VN_NEEDS_N**.

The window has \(18\) odd-odd starts and \(43\) landings, \(30\)
distinct \(y\). Intrinsic \(V\) is a function of \(y\). Relative
\(V_n\) is not. Incoming history varies at six values of \(y\) and
never changes \(V\). No subset of
\((\mathrm{parity},A,G,\rho,\mathrm{cell})\) is a proper quotient:
every fiber-bearing subset splits. On non-start landings,
\((G,\rho)\) and some enlargements predict \(V\) only because each
class has a single \(y\).

The canonical residual information is the current integer for
intrinsic constraints, and the pair \((\text{start},\text{current})\)
for start-relative constraints. The larger tuple is a history
certificate plus functions of \(y\).
