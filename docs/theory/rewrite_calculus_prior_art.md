# Rewrite-calculus prior-art and claim audit

**Purpose:** internal publication record. This page is not a theorem
ledger and does not change any evidence tag.

## Direct prior art

The closest source is Contejean, Marché, and Rabehasaina (CMR97),
*Rewrite Systems for Natural, Integral, and Rational Arithmetic*,
RTA 1997, LNCS 1232, 98--112,
[doi:10.1007/3-540-62950-5_64](https://doi.org/10.1007/3-540-62950-5_64).
An associated 1997 research report was issued by the Laboratoire de
Recherche en Informatique, Université de Paris-Sud. The authoritative
author bibliography gives no report number, so this project does not
invent one.

CMR97 is direct priority-destroying evidence for any broad claim that
this project first rewrites balanced-ternary arithmetic. It represents
integers with balanced digits and a postfix append constructor
\(x :_t a\) whose semantics is
\[
\llbracket x :_t a\rrbracket=3\llbracket x\rrbracket+a,
\qquad a\in\{-1,0,1\}.
\]
It provides arithmetic rewrite systems that are terminating and
confluent modulo associativity and commutativity of addition and
multiplication.

Other mandatory background is:

- Avižienis (1961), the classical redundant signed-digit construction
  for bounded carry propagation and parallel arithmetic;
- Heuberger and Prodinger (2003), finite automata for carry propagation
  in signed-digit systems, explicitly including balanced ternary;
- Frougny, Pelantová, and Svobodová (2011), local/parallel addition in
  non-standard numeration systems;
- Frougny, Pelantová, and Svobodová (2013), minimal digit alphabets for
  parallel addition;
- Frougny, Heller, Pelantová, and Svobodová (2014), fixed-block versus
  one-block parallel addition;
- Walters and Zantema (1994), terminating and ground-confluent
  arbitrary-radix arithmetic TRSs using digit application;
- Bergstra and Ponse (2016), a later comparison that explicitly records
  CMR97's balanced-ternary append semantics.

## CMR97 equivalence audit

### Representation dictionary

| CMR97 construct | This repository | Relation |
|---|---|---|
| balanced digits \(-1,0,1\) | `Trit` / \(\{-1,0,1\}\) | same digit values |
| \(x :_t a\) | \(I_a(x)=3x+a\) | same integer map |
| repeated postfix append | composition of section operators \(I_a\) | same positional representation, opposite presentation conventions may affect written order |
| balanced-ternary normal forms | canonical balanced words | same underlying integer representation |
| arithmetic symbols \(+,\times,-\) | outside `OpFrag`; handled elsewhere in the repository | CMR97 is broader as arithmetic syntax |
| AC arithmetic rewriting | no AC rules in the paper's `OpFrag` relation | different rewrite problem |
| removal of the least digit | \(D(n)=(n-\operatorname{lsd}(n))/3\) | standard inverse operation, explicit primitive only on this side |
| least digit observation | \(\operatorname{lsd}\) | mathematically implicit in append decomposition; not found as a central CMR97 operator |

The forward translation on representation terms is immediate:
\[
T(a)=a,\qquad T(x :_t a)=I_a(T(x)).
\]
Evaluation is preserved because both constructors denote \(3x+a\).
Conversely, a constructor-only term
\(I_{a_0}(I_{a_1}(\cdots I_{a_k}(0)\cdots))\) can be written as
repeated CMR97 append, with written order chosen to preserve evaluation.
Thus the section idea and the identity \(D(I_a(x))=x\) are not priority
claims.

### What transfers and what does not

The underlying integer representation transfers directly. CMR97's
addition and multiplication rules establish that balanced-ternary
arithmetic rewriting predates this project. The broad mathematics of
normalizing carries also transfers as background.

The paper's `OpFrag` theorem is not the CMR97 arithmetic theorem under a
renaming. `OpFrag` consists of open one-hole unary terms generated by
\(\{D,I_a,S,N\}\), contains neither `Add` nor `Mul`, and asks whether
irreducible open terms are unique representatives of functions
\(\mathbb Z\to\mathbb Z\). Its rule
\(N(D(t))\to D(N(t))\) is required for semantic injectivity.
CMR97 instead normalizes arithmetic terms built around digit
representation and works modulo AC for addition and multiplication.

This is a conceptual and formal distinction, but it does not make
digit append, balanced quotienting, or arithmetic rewriting new.
No source inspected in the bounded search states the exact open-term
theorem `unary_complete_canonical_form` or the factorization theorem
`add_not_DLocal`. Absence from this bounded search is not a universal
priority proof; the manuscript therefore makes no “first” claim.

### Status of \(D\)

For a canonical balanced expansion
\[
n=3q+a,\qquad a=\operatorname{lsd}(n),
\]
\(D(n)=q\) removes the least-significant digit. This is the ordinary
quotient operation inverse to append, not a newly discovered arithmetic
operation. The useful project choice is to make \(D\), its sections,
negation, and composition the primitive language of a small open-term
calculus. The resulting theorem statements about termination,
confluence, and semantic injectivity concern that language.

### Status of sections

\(I_a(x)=3x+a\) is exactly CMR97's digit append. The notation is retained
because it makes section identities and operator composition concise:
\[
D\circ I_a=\operatorname{id},\qquad I_0=S,\qquad
N\circ I_a=I_{-a}\circ N.
\]
These equations are reformulations of standard digit semantics. The
claim retained by the paper is the canonicality package for the exact
oriented unary grammar, not historical priority for the equations.

## Unresolved novelty questions

1. A broader database search could still locate an open-term destructor
   calculus closer to `OpFrag`; this audit establishes defensible
   positioning, not exhaustive priority.
2. The historical novelty of the exact `DLocal` factorization statement
   is not established. The paper can prove and use it without claiming
   priority.
3. Earlier proof-assistant formalizations of signed-digit streams and
   arithmetic exist. This audit did not establish that the Lean package
   is the first mechanization.

## Decision

`PROMOTE` the revised narrow paper. The surviving publication object is
not a new balanced-ternary arithmetic TRS. It is a formally verified
study of one explicit open unary operator grammar, with semantic
canonicity and an exact addition-state factorization obstruction. CMR97
and the signed-digit literature become central background. The research
engine and later residual-dynamics results remain a separate publication
direction.
