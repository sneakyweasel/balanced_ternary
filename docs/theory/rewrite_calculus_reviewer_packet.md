## Paper thesis

CMR97 already gives balanced-ternary arithmetic rewrite systems and
uses digit append with the same semantics as \(I_a(x)=3x+a\). Signed-digit
carry automata and parallel addition are also established prior art.
The paper therefore makes no priority claim for arithmetic rewriting,
sections, digit removal, or finite carry.

The narrower thesis is that the one-hole unary language generated by
\(\{D,I_a,S,N\}\) has a canonical rewrite presentation under exact
integer-function semantics. Its boundary at addition is an exact
failure of state factorization: the next-state output \(D(x+y)\) is
not determined by \((D(x),D(y))\). The balanced carry identity names
the missing least-significant-trit information, and the named
carry-free push-in system exhibits the same boundary as a
non-confluent critical peak.

This is not an impossibility theorem for addition or for arbitrary
rewrite systems.

## Central formal theorem

A binary output \(H:\mathbb Z^2\to\mathbb Z\) is `DLocal` when
\[
\exists G:\mathbb Z^2\to\mathbb Z\quad
\forall x,y,\quad H(x,y)=G(D(x),D(y)).
\]

Lean theorem:
```text
add_not_DLocal :
  ¬ DLocal (fun x y => DZ (x + y))
```

Minimal witness:
\[
D(0)=D(1)=0,\qquad
D(0+0)=0,\qquad D(1+1)=1.
\]

The carry identity
\[
D(x+y)=D(x)+D(y)+
\operatorname{carry}(\operatorname{lsd}(x),\operatorname{lsd}(y))
\]
is the structural explanation, not a replacement for the locality
theorem.

named peak; it is not a stronger universal theorem.

## What the paper does not claim

- Addition has no finite rewrite presentation.
- Signed-digit carry-managed addition is impossible.
- Every finite Add-tree system is incomplete.
- “CAS” is a formal mathematical category.
- The production operator-word table is confluent.
- The named push-in peak classifies all possible extensions.

Coefficient-word normalization is an explicit complete treatment of
integer sums outside the unary tree grammar.

## Maximality gate

The paper deliberately declines a universal maximality theorem. A
natural proof would require an independently defined class of
carry-free tree systems and a theorem that completeness forces
`DLocal (D ∘ Add)`.

Two short definitions were rejected as non-results:

1. defining “carry-free” by assuming `DLocal (D ∘ Add)` merely
   restates `add_not_DLocal`;
2. assuming the two peak descendants remain irreducible proves only
   peak persistence, not maximality.

A genuine bridge would require generic TRS metatheory outside the
bounded gate.

## Suggested falsifiers

A review should reject or revise the package if:

1. the output-factorization definition does not capture the claimed
   state boundary;
2. the witness does not establish failure of that factorization;
3. the unary semantic-injectivity theorem has unstated grammar or
   semantics assumptions;
4. the two descendants of the named peak join under the stated
   relation;
5. prior literature already proves this exact operator-fragment and
   locality package;
6. the draft presents the declined universal maximality statement as
   Lean verified;
7. digit append, carry automata, or parallel addition are described as
   originating in this work despite CMR97, Heuberger--Prodinger, or
   Frougny--Pelantová--Svobodová.
